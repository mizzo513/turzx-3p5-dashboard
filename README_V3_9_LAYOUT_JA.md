# TURZX 3.5インチ v3.9.0 — 480×320 二分割レイアウト

## 表示仕様
- **下段の独立したフッター枠を削除**。天気・列車の両パネルは画面下端の余白まで拡張します。
- 天気パネルを幅123px（x=5〜127）に縮小し、列車パネルを幅342px（x=133〜474）に拡張しました。
- 天気の地名は「白山市」など**自治体名のみ**表示。接頭辞「石川・」を削除します。
- **現在気温を整数**（例: `15°`）で表示。最高・最低気温も整数です。
- 列車欄の見出し「加賀笠間→金沢→津幡」「次の3本」は表示しません。
- 列車ごとに **①加賀笠間発 ②金沢着 ③金沢発 ④津幡着** の4つの時刻を独立した編集可能な項目として表示します。
- 3本の乗換候補を上下に表示し、金沢での**乗換時間・到着/発車番線**を併記します。
- 乗換時間が短い場合でも `（注意）` の文字列は表示しません。
- 直通運転は `直通（乗換不要）` と表示します。
- 更新時刻と時刻表注記は**天気枠・列車枠の内側**の最下部に表示します。
- 時計の秒表示、NTP、USB送信の180度回転、GitHub更新、座標・フォントサイズ・色編集は維持します。

## 旧レイアウト設定
V3.8.3以前で文字・パネルの座標やサイズをカスタマイズしていた場合は、新しい標準の配置へ自動移行します。旧カスタマイズ設定を `layout_backup_v383` に保持し、文字色・パネル配色は継続利用できます。天気の地域、COMポート、時刻表、更新間隔などの設定は変更しません。
**設定の保存時点で** `%LOCALAPPDATA%\TURZXDashboard\settings.json` に旧レイアウトのバックアップも記録します。

## ダイヤについて
収録済みIRいしかわ鉄道の2026-03-14改正の静的時刻表を使います。現在の運行・遅延・運休・臨時列車や実際の乗換可否は反映されません。3分乗換も表示されますが、現地での利用可能性は別途確認してください。

## 更新
V3.8.3の設定画面から `GitHubで最新版を確認` → v3.9.0への更新で適用できます。もし再起動に失敗する場合はGitHub ReleasesからEXEを手動ダウンロードして起動してください。

## 動作確認
GitHub Windows ActionsでPythonユニットテスト、PyInstaller単一EXE起動テスト、自動アップデーター結合テストを行います。実機の視認性とUSB送信は別途確認が必要です。
