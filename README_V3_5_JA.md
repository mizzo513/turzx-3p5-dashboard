# TURZX 3.5インチ 自動ダッシュボード V3.5

この版は、V3.4で実機動作が確認された **480×320・画像180°回転・COMポートUSBシリアル・compact秒更新** を継承します。

## 変更点

1. **`runtime_status.json` の常時更新を廃止**。設定画面は PC 内部の `127.0.0.1:48653` からステータスを取得します。画面表示や天気情報をインターネット公開する機能ではありません。旧 `runtime_status.json` は表示エンジンの起動時に一度だけ削除します。設定変更時の `settings.json`、必要時のログなどは引き続き保存されます。
2. **文字編集画面**。設定画面内「文字の大きさ・色・配置を編集」から変更。表示項目ごとに X/Y（画面左上基準、自然な向き）、フォントサイズ、文字色を設定。プレビューをクリックして移動もできます。実機表示中は「実機へ即時反映」を押します。文字が重なる可能性があるため、プレビューで確認して調整してください。
3. **Windows用単一EXEビルド**。`BUILD_ONE_EXE_WINDOWS.bat` をWindows 10/11 64bit上で実行すると、`dist\TURZX_3p5_Dashboard.exe` を生成します。EXEには表示制御、設定画面、Python実行環境、時刻表を同梱します。EXEをダブルクリックすると設定画面が開き、表示開始ボタンから同じEXEを背景モードで起動します。黒いコマンド画面は出ません。

**このZIPにはWindows用EXEそのものは含まれていません**。Windows実機のPython/ビルドツールで上記バッチを実行して生成してください。

### 単一EXE実行時の保存先

`%LOCALAPPDATA%\TURZXDashboard\` に設定の保存とログ出力を行います。EXE本体と配布物は1ファイルですが、設定・ログなどのランタイムファイルが完全にゼロになるわけではありません。`runtime_status.json` は作成しません。時刻表はEXE内部に同梱し、外部版 `schedule.json` が明示的に置かれている場合はそちらを優先します。

### 既存V3.4から更新する場合

1. V3.4の表示エンジンを **完全に停止** します。
2. V3.5 ZIPの内容を、既存の `turzx_dashboard.py` があるフォルダへ上書きコピーします。`.venv`、`settings.json`、`train_results.json` は削除しないでください。
3. `Open_Live_Settings.vbs` で設定画面を開くか `Start_Display_Hidden.vbs` で表示を開始します。
4. 秒が崩れた場合は設定画面から `safe_strip` に戻して確認します。

### 別PCへ単一EXEを移す場合

- EXEをUSBなどで移動し、ディスプレイを接続してEXEを起動します。
- 初回は設定を保存し、ポートを `AUTO` にしてください。
- 時刻表は同梱（2026/3/14改正、遅延・運休を反映しない予定データ）です。天気の取得にはインターネット接続が必要です。
- 配布時は `LICENSE-GPL3.txt` と著作権通知を添えてください。使用ライブラリのライセンスも確認してください。

### 診断

- WindowsのEXEビルドや実機USB転送は、この環境では実行・検証できません。
- ローカルIPCのポートを別ソフトが使用していると、設定画面でステータスが得られない場合があります。
- `python tests_v35.py` でコードと描画の基本テストを実行できます。
