# TURZX 3.5インチ 自動表示ダッシュボード V3.6.1

Windows 10/11 (64bit) 用、USB35INCHIPSV2系 (VID:PID 1A86:5722)・480×320・横向きの180度回転表示用。

## 今回の更新

- 時計と日付を `11/18(水) 13:15:00` のように並べて表示
- 上段の「天気・列車」を削除（上段の枠は保持）し、右下に `v3.6.1` を表示
- レイアウト編集：文字選択の黄色枠を実際の描画範囲へ合わせ、背後の設定画面のホイール誤動作を修正
- レイアウト編集：ヘッダー、天気枠、列車枠、列車1～3の枠、フッター枠の位置・大きさ・背景色・枠線色・角丸・枠線幅も変更可能
- 表示内容を変更すると稼働中のディスプレイへ設定を反映（秒のコンパクト差分更新を維持）
- EXE版に「更新ZIPを選んでアップデート」機能を追加
- `BUILD_EXE_AND_UPDATER_WINDOWS.bat` でEXEと更新ZIPをまとめて生成

## すでにV3.5を使用中の場合

まず旧版を停止してください。`TURZX_V3_6_Upgrade_Patch.zip` の内容を、現在のソース版の `turzx_dashboard.py` があるフォルダへ上書きすると、既存の `.venv`・`settings.json`・`schedule.json` を維持できます。

V3.5からは上段の日時表示を統合したため、旧版で個別に保存した `clock_hm`・`clock_seconds`・`date`・`title` の文字設定は新しい `clock_datetime` に引き継がれません。他の文字設定はそのまま引き継がれます。上段の新しい位置は編集画面から調整してください。

新規導入の場合：`START_HERE_Setup_and_Run.bat` を実行して環境を構築、続けて `open_settings_windows.bat` で設定を開きます。ディスプレイは1台だけ接続し、純正UsbMonitor/TURZXを終了してください。

## レイアウト編集

設定画面内「文字・枠の配置／サイズ／色を編集」から開きます。
左の選択リストはマウスホイールでスクロールできます。背景の設定画面とはホイール操作を分離しています。

プレビュー上の文字・枠をクリックして対象を選択し、そのままドラッグで移動できます。枠を選択すると黄色い四角形と右下のハンドルが表示され、ハンドルのドラッグで大きさを変更できます。右側の数値入力で微調整、文字色・枠線色・背景色も選択できます。

※枠を移動・拡大しても、枠内に見える文字やアイコンは自動で追従しません。必要に応じて別々に配置を変更してください。

## Windowsで単一EXEと更新ZIPを作る

1. Windows PCのソースフォルダ全体を展開し、Pythonを導入します（既存の `.venv` を使用可能）。
2. `BUILD_EXE_AND_UPDATER_WINDOWS.bat` を実行します。PyInstallerが必要に応じてインストールされます。
3. `dist/TURZX_3p5_Dashboard.exe` と `dist/TURZX_Update_v3.6.1.zip` が生成されます。
4. EXEは単体で起動できます。改訂版EXEで同じビルダーを走らせると、今後の更新ZIPを生成できます。

**初めてV3.6.1を導入するとき**：以前のV3.5 EXEには更新メニューがありません。最初はV3.6.1 EXEを手動でコピーして起動してください。**V3.6.1以降**は設定画面の「更新ZIPからアップデート（EXE版）」から更新できます。

更新ZIPは自動的にダウンロードされません。ユーザーが信頼する配布元から入手したZIPのみを手動で選択してください。`manifest.json` のファイル名・バージョン・サイズ・SHA256を検証しますが、発行元の電子署名による真正性は検証しません。

実行中のEXEは上書きできないので、Windows PowerShell補助スクリプトが画面表示を停止して旧EXEをバックアップし、同じ場所に新EXEを原子的に置換してから起動します。**インストール先フォルダに書込権限が必要**です。Program Files等に置かず、ユーザーフォルダを推奨します。

通常の利用では EXE 1つだけで動作します。ただし変更可能な設定・時刻表・ログ・アップデート一時ファイルは `%LOCALAPPDATA%\TURZXDashboard` 以下に外部保存されます。ファームウェアの更新は行いません。

## 含まれる時刻表と制約

列車データは、ユーザー提供の `schedule.json` から金沢→津幡を選びます。2026年3月14日改正ダイヤの静的データであり、遅延や運休を反映しません。天気はOpen-Meteoから取得し、地域は白山市が初期設定です。

## V3.6.1 (表示・列車候補の復旧)

- 旧V3.6差分パッチに不足していた `rail_core.py` / `schedule.json` を復旧パッチへ同梱。
  既存 `schedule.json` は上書きせず、欠損している場合のみ同梱版を追加。
- `ir_schedule` 使用時、利用者側の時刻表が未配置・破損した場合に、アプリ同梱の正常な時刻表へフォールバック。
- 設定画面の「列車候補・データを診断」で、選択中の取得元と実際の読み込みパス、候補を確認。
- 設定画面の「現在の設定で画面プレビュー」で、実機と同じPillow描画処理・実際の時刻表で作画。
  天気はAPIから取得できれば反映、取得前/失敗時には「未取得」と表示します。
- 「標準レイアウトへ戻す」で、過去の文字/枠の上書き設定を初期化し、事前に設定をバックアップ。
- 表示エンジンが古い場合、GUI側にバージョン不一致警告を表示。
- GUIのタイトルと編集画面のバージョン表示を、共通 `version_info.py` の `APP_VERSION` に統一。

更新時は一度表示エンジンを停止してください。ソース版へのパッチは `APPLY_PATCH_WINDOWS.bat` で
既存の `turzx_dashboard.py` が置かれたフォルダを選択します。EXE版の場合はパッチをEXEに
直接上書きできません。Windows用ビルダーでV3.6.1のEXEを再生成する必要があります。
