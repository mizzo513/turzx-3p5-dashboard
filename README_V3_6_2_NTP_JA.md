# TURZX 3.5 自動ダッシュボード V3.6.2 — インターネット時刻対応

## 新機能

- **NICT公開NTPサーバー `ntp.nict.jp` から日本標準時を取得**（UDP 123）。
- 起動直後に非同期同期し、以後は標準30分間隔で再同期。時刻はNTP取得時刻を基点にPC内の単調増加タイマーで進めます。PCの日時設定は変更しません。
- ネットワーク未接続・UDPポート遮断時はPC時刻で暫定表示。同期に一度成功していれば最長6時間はNTP基準で表示し、経過後はPCに切り替えます。
- 設定画面の稼働状態に **「時刻 NTP」／「時刻 PC (NTP未同期)」** を表示します。
- NTPサーバー名と再同期間隔（5～1440分）を設定画面から変更できます。失敗時の再試行は約60秒後。
- V3.6.1の白山市天気、金沢→津幡時刻表、180度表示、秒の小領域更新、即時設定反映、EXEアップデーターを維持。

## 配布ファイルと更新方法

**Pythonソース版を使っている場合**：`TURZX_NTP_v3_6_2_SourcePatch.zip` 内の `APPLY_PATCH_WINDOWS.bat` を実行し、表示プログラムのフォルダを選びます。既存設定と時刻表は保持します。適用前に表示エンジンを停止してください。

**単一EXE版を使っている場合**：現在のEXEのアップデーターは `manifest.json` と新しい `TURZX_3p5_Dashboard.exe` を含むZIPのみ受け付けます。Pythonソースの更新ZIPを直接読み込むことはできません。V3.6.2の**完全版**をWindows上で展開し、`BUILD_EXE_AND_UPDATER_WINDOWS.bat` を実行してください。生成された `dist\TURZX_Update_v3.6.2.zip` を、旧EXEの設定画面「更新ZIPからアップデート」から選択してください。

ビルドを行うWindows PCにはPython/PyInstallerが必要です。生成後の更新先PCにPythonは不要です。

## ネットワークについて

公式NICT NTP: https://www.nict.go.jp/sts/ntp.html

UDP 123の送受信がファイアウォールや企業ネットワークで禁止されている場合は時刻を取得できません。NTPによる時刻情報にはネットワーク遅延に基づく誤差があり、絶対精度は保証できません。NTP通信は暗号署名付きではありません。

## 確認方法

1. V3.6.2を起動します。
2. 設定画面下部の稼働状態が `時刻 NTP` になれば同期成功です。
3. `時刻 PC (NTP未同期)` の場合は `logs/dashboard.log` の `NTP unavailable` を確認してください。
4. 秒表示・天気・列車を確認してください。表示はPCの時刻設定を変更しません。
