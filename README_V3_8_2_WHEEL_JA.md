# TURZX Dashboard v3.8.2: レイアウト数値欄のホイール操作

## 変更内容
- 「文字・パネル枠の編集」画面でX座標・Y座標・文字サイズ・枠の幅/高さ・角丸・枠線の太さにマウスカーソルを合わせてマウスホイールを回すと数値を変更できます。
- 上に回すと+1、下に回すと-1。Shiftを押しながらの操作では±10です。
- 数値が画面外や許容範囲外にならないよう自動制限します。
- 色の入力欄や項目リストのホイール動作は変更しません。
- 変更はその場で**編集画面のプレビューのみ**に表示し、設定ファイルへの保存・実機へのUSB転送は行いません。
- **「実機へ即時反映（保存）」ボタンを押したときにだけ**保存して、実行中の表示ソフトへ反映します。
- 編集画面を保存せず閉じれば未反映の変更は破棄されます。
- 画面レイアウトや時計の瞬間更新・天気・加賀笠間→金沢→津幡時刻表示・GitHub自動更新は従来のままです。

## 更新
v3.8.1の設定画面→「GitHubで最新版を確認」からv3.8.2へ更新可能です。実機更新は要動作確認。

## 開発者向け
`python -X utf8 -m unittest discover -v -p "tests_*.py"` でホイール処理の境界値と未保存動作をテストします。
