# TURZX V3.9.3 — 起動時の実機表示と文字グループ一括編集

## 追加機能

### 1. TURZX起動時に実機表示を自動開始
- **設定画面の起動後、USBディスプレイの表示エンジンも自動で起動**します。初期設定はONです。
- 設定画面「表示・時計」タブに「アプリ起動時に実機への表示を自動開始」を追加しました。チェックを外して「設定を即時反映」で保存すると、次回から自動表示しません。
- 既に同じバージョンの表示エンジンが動作している場合は**二重起動をしません**。
- GitHub更新直後に旧エンジンが終了途中の場合は、停止を確認するまで再確認してから起動します。
- USB接続が失敗した際は従来の再試行処理を使用します。Windowsのログイン時に自動起動する設定は**追加していません**（EXEを起動した時の動作です）。

### 2. 関連する文字の一括調整
従来の「文字・枠の配置／サイズ／色を編集」画面に「**文字グループ一括調整**」ボタンを追加しました。文字は従来どおり1件ずつでも編集できます。

次のグループを選び、「左右移動(px)」「上下移動(px)」「文字サイズ増減(px)」を指定して「プレビューへ適用」を押すと、グループ内の文字の相対位置・色を維持しながらまとめて変更します。

- 天気：見出し・天候・現在気温
- 天気：項目名5種／数値5種
- 列車：3本の駅名を一括／3本の時刻を一括／番号・乗換案内・旧モード時刻
- 列車1・2・3：それぞれの4駅ラベル、4時刻を個別グループ単位で調整

**プレビューの一括変更は、その場では保存しません。** 元画面の「実機へ即時反映（保存）」を押した時点で、従来の `text_styles` へ保存され実機に反映されます。個別の文字位置・色・サイズは保存・次バージョンへ引き継ぎます。

文字がグループの所属する枠からはみ出す変更、文字サイズが8～52pxの範囲を超える変更は、グループ全体を未変更のままエラーにします（個別文字だけをずらして崩すことはしません）。

### 3. 従来機能は維持
- V3.9.2の4タブ設定画面、時計・NTP、天気API選択とWeatherAPIキー、IR列車時刻、編集機能、GitHub自動更新はそのままです。
- 実機の480×320描画レイアウトは変えていません。

## 操作
1. V3.9.3へ更新後、EXEを起動します。
2. 既定では実機表示が自動で開始されます。「表示・時計」でOFFに変更できます。
3. 一括編集は「外観・更新」→「文字・枠の配置／サイズ／色を編集」→「文字グループ一括調整」から実行します。
4. グループと変更量を指定し、「プレビューへ適用」→ 元画面で「実機へ即時反映（保存）」を押します。
