# TURZX V3.9.4 — 自動表示開始・文字一括編集・単位分離・設定画面縮小

## 変更内容

### 1. アプリ起動時にUSB表示を自動開始

WindowsでTURZX EXEを起動すると、設定画面の起動に続き、バックグラウンド表示エンジンが自動起動します。

- 既に表示エンジンが動いている場合は二重起動しません
- 古いバージョンの表示エンジン終了を待つ処理を維持します
- 自動起動では**保存済み設定を読み込むだけで上書き保存はしません**
- 「表示・時計」タブの「アプリ起動時に実機への表示を自動開始」でOFFにできます
- 実機未接続時は従来どおり再接続を試みます

### 2. 文字グループ一括編集と個別設定チェック

文字・枠のレイアウト編集で、関連する文字を選択すると標準で**同系統グループ単位**でX/Y座標と文字サイズを変更します。ドラッグ／数値入力／数値欄ホイールが対象です。

- 「個別設定（この文字のみ変更）」をONにすると、選択した文字のみ調整
- 列車1本ごとの4時刻、駅名、3本共通の時刻など、同じ枠内でグループ化
- 天気のラベル／数値／単位は別グループに分離
- グループ操作は同じ増分を各文字に適用し、色・相対間隔を維持
- 不正な座標・文字サイズになる操作はまとめて拒否します
- 既存「文字グループ一括調整」ダイアログも使用可能
- **実機へ反映されるのは「実機へ即時反映（保存）」を押したときだけ**

### 3. 天気の数値と単位を独立編集

天気欄の以下をそれぞれ2項目として扱います。

| 数値 | 単位 |
| --- | --- |
| 現在気温 | ° |
| 最高・最低気温 | °C |
| 降水確率 | % |
| 湿度 | % |
| 風速 | m/s |

数値と単位はそれぞれ独立した座標・サイズ・色を設定できます。天候取得方式や雨量優先判定（無効）は変更しません。

### 4. 設定画面の横幅縮小

- 初期画面サイズを**725×505px**に変更
- 緯度と経度を横並び表示
- 列車の更新間隔・表示本数を横並び表示
- NTPなどの入力欄やAPIキー欄を用途に応じた幅へ調整
- 4タブと下部固定の保存・表示・停止ボタンを維持

## 設定の引き継ぎ

設定保存先は従来どおり `%LOCALAPPDATA%\TURZXDashboard\settings.json` です。文字・枠のカスタマイズ、WeatherAPI.comのキー、電車・時計等の設定を引き継ぎます。新たに追加した単位項目は標準配置から始まり、それぞれ個別に編集できます。

## 更新方法

V3.9.3以前で「GitHubで最新版を確認」を押すか、ReleasesからV3.9.4のEXEを取得してください。旧EXEはバックアップし、更新が完了するまで保存済み設定を削除しないでください。

## 確認事項

Windows ActionsにてPython回帰テスト、Tk画面のテスト、EXE起動スモークテスト、更新補助スクリプトの実体験証を実施します。TURZX実機での表示位置やスクロール量の最終確認は別途必要です。
