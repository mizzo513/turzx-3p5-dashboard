# TURZX 3.5インチ v3.8.0 経由乗換表示

- 初期表示: 加賀笠間 → 金沢 → 津幡
- 時刻: 加賀笠間発、金沢着、金沢発、津幡着（4時刻）
- 金沢の乗換待ち時間と到着・発車番線、既知の直通運転を表示
- 乗換時間4分以下は「注意」。接続保証ではありません
- 設定画面で金沢→津幡の直通区間表示へ切替可能
- 以前のsettings.jsonにir_routeがなくても新表示が初期選択されます
- GitHub自動更新、白山市の天気、NTP時計、180度回転、文字・パネル編集を維持

## データの制約

ユーザー提供のschedule.json（IRいしかわ鉄道2026年3月14日改正時刻表）から静的な経路を計算しています。遅延・運休・臨時列車・運用変更・実際の乗換可否をリアルタイム反映しません。

## 更新方法

v3.7.0を起動して設定画面の「GitHubで最新版を確認」→「更新する」からv3.8.0へ更新できます。処理中に別のTURZX表示プロセスが動いていないか確認してください。

## テスト

`python -X utf8 -m unittest discover -v -p "tests_*.py"`

EXEビルドとGitHub Releasesへの公開後、実機で表示状態を確認してください。
