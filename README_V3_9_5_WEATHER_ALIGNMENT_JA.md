# TURZX V3.9.5 — 天気欄の数値右揃え・単位左揃え

V3.9.4をベースに、天気パネルの「最高」「最低」「降水」「湿度」「風」の各行を揃えました。

- 数値は **右揃え**。1桁・2桁・3桁の数値や小数値でも、標準配置の右端 `x=104` を共通の基準とします。
- 単位（`°C`、`%`、`m/s`）は数値から独立し、標準配置で `x=106` に **左揃え** します。
- 数値と単位はそれぞれ個別の文字要素のまま。V3.9.4で実装した個別編集／一括編集を維持します。
- 数値のX座標を移動したときは、その数値欄の右端が相対的に移動します。文字サイズを変更しただけでは右端は移動しません。
- 文字の色・フォントサイズ・位置の保存形式は変更しないため、既存設定を維持できます。
- 天気API（WeatherAPI.com / Open-Meteo）・降水量優先判定（無効）・鉄道・NTP・自動USB表示・GitHub自動更新は変更していません。

この変更は描画ルールの変更です。現在気温の大きな数字は従来どおりです。標準レイアウトと個別設定を確認してください。

## 確認方法
GitHub Actionsでのユニットテスト、Windows EXE起動テスト、アップデーターの結合テストを実施。実機での視認性は別途確認してください。
