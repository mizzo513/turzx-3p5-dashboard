# TURZX v3.9.2 — コンパクトなタブ式設定画面

## 変更内容

設定ウィンドウを従来の **850×715px の縦長一画面**から、初期サイズ **800×540px** の4タブ構成に変更しました。

| タブ | 主な機能 |
| --- | --- |
| 表示・時計 | USBポート、秒表示、12時間表示、NICT NTP設定、秒の更新方式 |
| 天気 | WeatherAPI.com / Open-Meteoの切替、APIキー、地域・緯度経度、更新間隔 |
| 乗換 | IR時刻表、表示区間、列車数・更新間隔、CSV/診断/公式時刻表 |
| 外観・更新 | 文字・枠の編集、プレビュー、レイアウト初期化、GitHub自動更新、更新ZIP |

ウィンドウの最下段に **「設定を即時反映」「天気APIテスト」「表示開始」「表示停止」「終了」** を常時表示します。各タブは独立したスクロール領域を持つため、Windowsの文字表示倍率を上げても、各機能へアクセスできます。

レイアウト編集画面を含む既存の設定機能と、設定の保存形式 (`%LOCALAPPDATA%\TURZXDashboard\settings.json`) は変更していません。**保存済み文字位置・色・枠サイズ、WeatherAPI.com APIキー、列車設定は引き継がれます。**

変更は設定画面のGUIのみです。TURZX実機へ送信する480×320画面、天候判定、列車ダイヤ、NTP時計は変更していません。

## 使用方法

1. V3.9.1の設定画面から「GitHubで最新版を確認」を実行するか、ReleasesからV3.9.2のEXEを取得します。
2. V3.9.2を起動すると4タブの設定画面が表示されます。
3. タブを移動して項目を変更し、下部の「設定を即時反映」で保存します。
4. 既存の文字・枠の配置は「外観・更新」タブから編集できます。

## 検証

GitHub Windows ActionsでPython回帰テスト、Tkの設定画面起動テスト、PyInstaller単一EXE起動テスト、および更新用結合テストを実行します。画面の見え方はOSの表示倍率によって多少異なります。
