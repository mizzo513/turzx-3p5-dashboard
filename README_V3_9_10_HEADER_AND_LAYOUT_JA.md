# TURZX 3.5 Dashboard V3.9.10 — 更新時刻の集約と画面調整

## 画面上部
- 時計枠の右上に「天気 HH:MM」「乗換 HH:MM」を縦並びで表示
- 最下段に既存の「v3.9.10」を表示、右端をそろえる
- データ取得前は「天気 --:--」「乗換 --:--」と表示
- 時計と更新時刻の領域を分離し、時計の秒更新では更新時刻を再送しない
- 乗換のデータが同じでも取得時刻が変わった場合、画面を更新する

## 空いた表示領域の活用
- 天気枠の下段にあった更新時刻と横線を削除
- 天気の5行（最高／最低／降水／湿度／風）の縦間隔を広げ、文字サイズを調整
- 乗換枠の下段にあった更新時刻と横線を削除
- 列車3件の各カードを高さ方向に拡張し、時刻・駅名・乗換案内を見やすく調整
- 時刻表出典の小さな注記は乗換枠の下部へ残す

## 設定画面
- タイトル「TURZX 3.5 設定 V3.9.10」の右隣に「更新確認」ボタンを新設
- すべてのタブから同じ更新確認ボタンを使用可能
- 外観・更新タブ内の重複確認ボタンは削除。ZIP手動更新は維持

## 旧版設定の引き継ぎ
- 既存のテキスト・枠スタイルを保持し、新規標準座標との差分だけ移動
- サイズ・色・列幅はユーザー設定を維持
- 移行前のスタイルを layout_backup_v399 にバックアップ
- 新レイアウト revision は 397
- USB再接続・5fps可変スクロール・総合天候判定の処理を維持

## 検証
- Windows GUIのタイトル横更新ボタン、全タブ表示をテスト
- 日付時刻／更新時刻／バージョンの領域分離をテスト
- 3つの列車枠と天候文字のボックス配置、旧スタイル移行をテスト
- Windows EXE／更新ZIPの生成と自動更新の回帰テスト
- 物理TURZXでの細かい文字の見え方は実機確認が必要
