# TURZX V3.9.6 — 数値・単位修正と公式運行情報テロップ

## 天気枠の修正
- 風速の数値を `x=74`、30px幅とし、最高／最低／降水／湿度と同じ右端 `x=104` に揃えました。
- 現在気温と最高・最低の温度単位をすべて **℃** に統一し、日本語対応フォントを利用します。
- 数値と単位の独立編集・文字グループ編集は維持します。

## 公式運行情報
乗換枠の最上段に、短い日本語の運行案内を1行で表示する欄を追加しました。長文は表示欄の内部だけを横に流します。下部の3本の列車候補は時刻の位置を下げ、表示を維持しています。

**公式ページ取得先**
- IRいしかわ鉄道公式トップで実際に使われている公開運行情報JSON：`https://www.ishikawa-railway.jp/train_state.json`
- 公式詳細ページ：`https://www.ishikawa-railway.jp/ishi-train/`
- JR西日本公式（七尾線を含む北陸エリア）の公開英語版ページ：`https://global.trafficinfo.westjr.co.jp/en/hokuriku`
- JR西日本の日本語公式確認ページ：`https://trafficinfo.westjr.co.jp/?areaId=1`

2026年1月のサイト更新以降、JR西日本日本語ページの本文はJavaScript表示が中心であるため、取得可能な公式英語版に掲載された七尾線の状況を**短い日本語で要約**します。英語版には機械翻訳由来の誤りが含まれる可能性があります。情報取得は公式の公開Web表示を利用し、非公開APIや非公式の乗換情報サイトから運行情報を取得しません。

**フィルター**
- IRいしかわ鉄道は加賀笠間～金沢～津幡と重なる区間の情報、またはIR線全体への影響を示すお知らせだけを表示します。
- 七尾線は津幡・金沢に言及する影響区間、または七尾線全体に対するお知らせだけを表示します。羽咋～七尾等、明示的に離れた区間のみの障害は表示しません。
- 関係情報がない場合は、公式情報を確認できた路線の状態を表示します。**取得できなかった場合や影響範囲が曖昧な場合は「未確認」**とします。
- この欄は運行上の注意表示であり、収録時刻表に基づく列車発着時刻や乗換候補を自動補正する機能ではありません。

**通信頻度・描画**
- 初期値では5分に1回、IRとJRそれぞれの情報を非同期取得します。5～60分の範囲で設定できます。
- 長い文字列は約1.7秒おきに16pxずつ横移動させます。USBには運行情報の細い一段のみを更新し、通常の時計表示・天気・列車表示への負荷を抑えます。
- 「乗換」タブに取得ON/OFF、確認間隔、両社の公式ページを開くボタンを追加しました。

## 以前のレイアウト設定について
保存先は従来どおり `%LOCALAPPDATA%\TURZXDashboard\settings.json` です。天気APIキー・文字色・サイズ・横位置・列車の設定を保持します。
運行情報の1行を上に確保するため、保存された既存の列車時刻文字のY座標は段ごとに自動調整します。変更前の文字／枠の設定は `layout_backup_v395` に保持します。以前の風速X座標が旧標準値71のまま保存されていた場合、74に正規化します。それ以外の意図的な座標調整は基本的に維持します。

## 注意
JR西日本公式サイトの運行情報は、公式の説明でも実際の運行と差がある場合があるとされています。情報利用時は公式サイトで最新状況を確認してください。データの取得に失敗した際、架空の運行情報を補完することはありません。
